# Ecos del Silencio

Archivo interactivo de reliquias de la exploración espacial, construido con
React, TypeScript y Vite. La aplicación permite recorrer un radar del Sistema
Solar, consultar expedientes históricos y completar tres minijuegos.

La documentación completa está en
[DOCUMENTACION.md](./DOCUMENTACION.md).

## Inicio rápido

```bash
npm install
npm run dev
```

Comandos disponibles:

| Comando | Uso |
| --- | --- |
| `npm run dev` | Servidor de desarrollo Vite con HMR |
| `npm run build` | Comprobación TypeScript y compilación de producción |
| `npm run lint` | Análisis ESLint |
| `npm run preview` | Servir localmente la compilación de producción |

Requiere Node.js compatible con las versiones declaradas en las dependencias
del proyecto.
